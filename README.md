# Heart Disease Early Risk Prediction Using Multi-Dataset Analysis

## About the Project

This project presents a machine learning-based framework for **early heart disease risk prediction** using multiple heart disease datasets. The system focuses on data analysis, preprocessing, machine learning model comparison, and interactive visualization to identify patterns and factors associated with heart disease.

The project analyzes datasets from **Cleveland, Hungary, Switzerland, and Long Beach** and provides a unified approach for predictive analysis and location-wise comparison.

## Objectives

* Perform data preprocessing and data quality analysis.
* Conduct exploratory data analysis to identify significant patterns.
* Perform feature engineering and feature selection.
* Develop and compare machine learning classification models.
* Evaluate models using standard performance metrics.
* Perform location-wise analysis across multiple datasets.
* Provide interpretable insights into model predictions.
* Develop an interactive dashboard for prediction and visualization.

## Machine Learning Models

The project evaluates the following classification algorithms:

* Logistic Regression
* Decision Tree
* Random Forest
* K-Nearest Neighbours (KNN)
* Support Vector Classifier (SVC)

## Evaluation Metrics

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC
* Confusion Matrix

## Dataset

The project uses the UCI Heart Disease datasets collected from:

* Cleveland, USA
* Hungary
* Switzerland
* Long Beach, USA

The datasets contain clinical attributes such as age, sex, chest pain type, resting blood pressure, cholesterol, maximum heart rate, exercise-induced angina, and other cardiovascular-related features.
